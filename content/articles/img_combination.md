## 一、核心痛点：组合商品的主图困局

### 1.1 典型业务场景

| 场景 | 举例 | 产品特点 |
|------|------|----------|
| **节日礼盒** | 春节礼盒、中秋礼盒、端午礼盒、年货大礼包 | 多品类组合，节日性强，时效要求高 |
| **员工福利** | 企业团购礼包、节日福利套装、年会礼品 | 品类杂、数量多、定制化需求 |
| **坚果礼盒** | 每日坚果、混合坚果、干果礼盒 | 单品多（8-12 种），需展示每一种 |
| **日化套装** | 洗护套装、化妆品礼盒、清洁用品组合 | 瓶瓶罐罐多，排列要求整洁 |
| **食品礼盒** | 糕点礼盒、零食大礼包、茶叶礼盒 | 单品大小不一，需协调比例 |

### 1.2 这些商家面临的具体问题

```
┌─────────────────────────────────────────────────────────┐
│                    组合商品主图制作流程                     │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. 拍摄/获取每个单品的照片                                │
│     ↓                                                   │
│  2. 对每个单品进行抠图去背景                               │
│     ↓                                                   │
│  3. 手动调整每个单品的大小、位置、角度                       │
│     ↓                                                   │
│  4. 排列组合成一个美观的整体                               │
│     ↓                                                   │
│  5. 添加背景、文案、装饰元素                               │
│     ↓                                                   │
│  6. 导出为电商平台要求的尺寸                               │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.3 数据说话

| 指标 | 现状 |
|------|------|
| 一款 10 件套礼盒的主图制作时间 | **4-8 小时**（美工手动抠图+排版） |
| 美工日均处理能力 | **3-5 款**礼盒主图 |
| 外包设计费用 | **200-500 元/款**（简单排版）|
| 换季/节日高峰期 | 排队等 3-7 天，错过销售窗口 |

### 1.4 核心矛盾

> **组合商品的主图制作，本质上是"多单品抠图 + 排版组合"的重复劳动**
>
> - 每个单品都要抠图 → 重复操作 N 次
> - 排版全靠手工拖拽 → 依赖美工经验
> - 换个背景/换个布局 → 又要重新调整

## 三、真实场景案例

### 案例一：春节坚果礼盒

**背景：** 坚果供应商，一款 10 装坚果礼盒，需制作主图上架淘宝

**传统流程：**
1. 10 个单品分别拍照 → 10 张照片
2. 美工逐个抠图 → 2 小时
3. 手动排列组合 → 1.5 小时
4. 调整大小比例、对齐 → 1 小时
5. 加背景、加文案 → 0.5 小时
6. 导出多尺寸 → 0.5 小时
7. **总计：5-6 小时，外包费 300-500 元**

**AI 流程：**
1. 上传 10 张单品照片 → 2 分钟
2. AI 自动抠图 → 30 秒
3. 智能排列组合 → 1 分钟
4. 微调位置、选择背景 → 5 分钟
5. 导出多尺寸 → 1 分钟
6. **总计：10 分钟，成本约 5 元**

**效果：** ⏱️ 效率提升 **30 倍**，💰 成本降低 **95%**

---

### 案例二：企业员工福利礼包

**背景：** 礼品公司，中秋为客户定制员工福利礼包，每套 8-12 件单品

**痛点：**
- 客户要求"先看效果图再下单"
- 每个客户需求不同，单品组合不同
- 传统方式：先沟通需求 → 设计出图 → 客户确认 → 再采购

**AI 解决方案：**
1. 客户现场提供单品照片
2. 销售当场上传 → 10 分钟出效果图
3. 客户确认方案 → 当场下单
4. **成交周期从 3-5 天缩短到 1 小时**

**效果：** 📈 签单率提升 **40%**，客户满意度大幅提升

---

### 案例三：日化品套装主图

**背景：** 日化品牌，洗护套装包含 6 个瓶瓶罐罐

**痛点：**
- 产品形状不规则，手动抠图费时
- 瓶子高矮不一，排版比例难协调
- 需要白底图、场景图、详情页图等多套

**AI 解决方案：**
1. 上传 6 个单品图 → AI 抠图
2. 自动调整比例，智能排列
3. 一键切换：白底图 / 渐变背景 / 场景背景
4. 导出多套素材

**效果：** 🎨 设计质量提升，📦 产出量提升 **5 倍**

## 五、项目总结：AI 赋能真实业务，解决实际问题

### 我们解决的是什么问题？

**不是"锦上添花"，而是"雪中送炭"。**

电商行业每年有数以百万计的组合商品需要制作主图——春节礼盒、中秋月饼、坚果大礼包、日化套装……这些商品的共同特点是：**多个单品组合，需要分别抠图，再排列成一张主图。**

这是一个**高频、刚需、但效率极低**的工作：
- 美工每天重复"抠图 → 排版 → 导出"
- 卖家等图等到错过上新窗口
- 供应商给每个平台做不同尺寸的图，苦不堪言
- 销售需快速呈现组合方案给客户
